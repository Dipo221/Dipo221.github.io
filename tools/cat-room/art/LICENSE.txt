art/ 的素材來源
================

disi-16.png
-----------

自己畫的，沒有第三方授權，要怎麼改怎麼散布都可以。

規格：48x48，切成 3 欄 x 3 排、每格 16x16，共 9 格。
每一排一個姿勢，播放順序與幀速寫在 ../sprites.js 的 manifest。

它不是用繪圖軟體畫的，是資料算出來的：

    disi.py    像素資料。一格一個字元的地圖 + 七色調色盤。改圖只改這支
    pixel.py   把資料算成 PNG，另外吐校對圖與 GIF，跑 lint

    python pixel.py     （要 Pillow）

輸出裡只有 disi-16.png 進版控。proof.png / squint.png / *.gif 是校對用的，
跑一次就重生，列在 .gitignore。

畫的過程值得記一筆：畫的人看不見自己畫的東西，是靠推座標把像素排出來的。
所以 pixel.py 的重點不是產素材，是產一張看得懂的校對圖——放大 20 倍、加格線、
加座標尺，才有辦法講「(5,5) 那格拿掉」而不是「眼睛怪怪的」。
lint 則守著三件事：相鄰兩幀的差異（照真實播放順序，含接回第一幀那段）、
頭只能整塊平移不能變形、行長與色盤。每一條都對應一個真的犯過的錯，
理由寫在那兩支 .py 的註解裡。


在這之前用的是別人的素材
------------------------

    16 bit kitty (free) by Maze.Bit.Boutique
    https://mxmaze.itch.io/16-bit-kitty-free
    CC BY 4.0

那個檔案（cat-16.png）已經從 repo 移除，所以標示義務結束了——
留著這幾行是記錄，不是義務。歷史 commit 裡還找得到那張圖，
但那些 commit 當下的 LICENSE.txt 也帶著完整出處，各自是自洽的。

它教會這包素材幾件事：描邊用暖棕不用純黑、睜眼是 1 寬 2 高的豎條、
閉眼是 2 寬 1 高的橫條、腿之間要留透明格。技法有學，格子沒有抄。


當初為什麼這麼在意授權
----------------------

這個 repo 是公開的，把圖 commit 進來就等於「散布」，
所以素材的授權必須明確允許散布，不能只是「可以用在你的遊戲裡」。

找過的其他幾個：

  Catset (seethingswarm)      動畫最齊（23 種），但條款明寫
                              "These assets are not to be openly distributed"，
                              而且要 $19.99 —— 不能用。

  2D Pixel Art Cat Sprites    免費可商用，但散布條款指向 Patreon 頁面、
  (Elthen)                    沒有講清楚公開 repo 算不算 —— 不確定就不要用。

  Cat Sprites (Shepardskin)   CC0，散布沒問題，但只有 walk/run，
                              沒有睡覺 —— 這個遊戲主要就是在看貓睡覺。

最後選了 CC BY 4.0 的那個，因為它明確允許重新散布，只要標示出處。

這一輪比較的結論後來自己失效了：素材改成自己畫的，上面這些限制都不存在了。
但當初為了「隨時換得掉」而把 manifest 拆成獨立一層的決定沒有白費——
真的要換的時候，動的只有 ../sprites.js 一支，遊戲邏輯一行都沒碰。
